Take it home

The screensaver runs this exact piece, live. It is not a recording: it pulls the art from the web, so it updates itself as new things ship. Silent by design, and it fills every display you have.

download
  1. Unzip it. You get SKLZ.saver.
  2. Double-click it. macOS asks whether to install for you or for everyone; either is fine.
  3. It opens System Settings → Screen Saver with SKLZ selected.
  4. Hit Options… to choose what it shows: the living art, demo mode (a new look every 3 minutes), or one specific board from a share link you made.
  1. Unzip it. You get SKLZ.scr.
  2. Right-click it and choose Install. Windows opens Screen Saver Settings with SKLZ selected.
  3. Or copy it into C:\Windows\System32 to make it available for every user.
  4. It needs the Edge WebView2 runtime, which Windows 10 and 11 already ship.

Signed and notarized by Apple, so it installs without a Gatekeeper warning.

Not code-signed, so SmartScreen will object the first time: click More info, then Run anyway. The source is in the repo if you would rather build it yourself.

This is a living artwork, not a video. Everything you see is drawn live and set to a three-hour mix, and nearly all of it is yours to bend: dozens of dials, palettes, and toggles behind the gear. Or skip the knobs and just talk to the skull. It listens in plain language, turns what you ask into the scene in front of you, and when you ask for something it cannot do yet, it interviews you about the idea and sends it to the artists. The piece grows this way. Some of what you are looking at began as a stranger's request.
